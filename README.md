# 🚀 Node.js + Redis Visits Counter

A small Express app that counts page visits using Redis, run with Docker Compose.

## 📋 Prerequisites

- 🔧 [Git](https://git-scm.com/downloads)
- 🐳 [Docker & Docker Compose](https://docs.docker.com/get-docker/)

## ▶️ Run

```bash
git clone https://github.com/adhamgamal22/<repo-name>.git
cd <repo-name>
docker compose up --build
```

Then open 🌐 <http://localhost:8081> and refresh to watch the counter increase.

## 🛑 Stop

```bash
docker compose down
```

## 🧱 Stack

- 🟢 Node.js (Express)
- 🔴 Redis
- 🐳 Docker & Docker Compose
